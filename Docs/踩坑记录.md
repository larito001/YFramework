# 踩坑记录

> 范围:**"Editor 正常、真机/打包/特定平台异常"** 这类不在编译期暴露、只在设备上炸的坑,外加几处易反复踩的工程约定。
> 每条结构固定:**现象 / 根因 / 排查 / 修法 / 防复发**。新踩到的坑往这里加,能 grep 检测的同时在 `pitfall-scan` skill 里补一条检查(见文末「skill 检查项映射」)。
>
> 黄金法则:**凡是"Editor 好、真机坏",先怀疑这四类**——① shader/变体被打包裁剪 ② 编译宏 / 平台 `#if` 门控 ③ 资源不在 `Resources/`(或 AB)没进包 ④ IL2CPP/AOT 裁剪反射。

## 1. 真机模型/材质变品红(shader 被打包裁剪)

**现象**:Editor 里模型正常,真机上整块变**品红**(magenta)。本项目首次出现在装备界面、图鉴、加载页的离屏预览,以及第一人称手持枪。

**根因**:品红 = Unity 的 "missing/error shader" 兜底色,意味着材质拿不到可用 shader。打包时 Unity / URP 会**裁剪掉"没有被任何打进包的序列化资产引用"的 shader 及其变体**。两种典型触发:

1. **运行时 `Shader.Find(...)` 临时造材质**:`new Material(Shader.Find("Universal Render Pipeline/Unlit"))`。`Shader.Find` 不算"打包期引用",没有任何 `.mat` 资产引用这个 shader → 变体被裁 → 真机 `Shader.Find` 拿到被裁的 shader → 品红。本项目的 `WeaponModelUtil.MakeUnlit` 就是这个。
2. **URP 里用了内置(Built-in)shader**:`Standard` / `Diffuse` 等内置 shader 在 URP 渲染管线下**不被支持**,直接品红(这种 Editor 里也是品红,容易早发现)。

> ⚠ **关键认知:把 shader 加进 `Project Settings → Graphics → Always Included Shaders` 不足以救 URP**。Always Included 只保证 shader **资产**进包,**不阻止 URP 的变体裁剪(Shader Stripping)**删掉具体变体。运行时造的材质用的变体若没被任何序列化材质"占住",照样被裁,真机照样品红。

**排查**:
- 全仓搜 `Shader.Find`:`rg "Shader\.Find" client/Assets/Scripts`。区分**运行时**(`GamePlay/`、`Framework/`)与**编辑期**(`Editor/`)。
- 编辑期 `Shader.Find`(builder 脚本里)通常安全——它把材质烘进预制体,shader 随预制体(在 `Resources/`)进包。
- 运行时 `Shader.Find` 才危险,尤其是 `new Material(Shader.Find(...))` 这种临时材质。
- 看真机日志有没有 shader 相关 warning;`Custom/*` 自定义 shader 还可能在移动端报编译错(见 [TapTap 文档 §11](../client/Docs/TapTap与广告SDK集成.md) 的 `LerpWhiteTo` 一条)。

**修法(本项目正解)**:**让一个序列化的 `.mat` 资产引用这个 shader,放进 `Resources/`,运行时从它 `Instantiate`**——打包器会收集到该材质的 shader 变体,运行时材质复用同一变体即可正常渲染。
- 实例:`Assets/Resources/Materials/UnlitPreview.mat`(URP/Unlit)+ `WeaponModelUtil.MakeUnlit` 从它 `new Material(template)`,只改主纹理/颜色不动 keyword(保持同一变体)。
- 退路:在 `MakeUnlit` 里模板缺失时才回退 `Shader.Find`(仅供 Editor / 兜底)。

**防复发**:
- 运行时要用的 shader,**一律确保有序列化资产引用它且该资产进包**(在 `Resources/` 或被 `Resources/` 预制体引用)。`Resources.Load<Shader>(...)`(如 `AnimalSystem` 的 `AnimalGold`,shader 在 `Resources/Shaders/`)天然安全。
- URP 项目里**不要用内置 `Standard`**;用 `Universal Render Pipeline/Lit`(guid `933532a4fcc9baf4fa0491de14d08ed7`)/`Unlit`(guid `650dd9526735d5b46b79224bc6e94025`)。
- 仍偶发被裁时的兜底:URP Global Settings 关 "Strip Unused Variants",或把材质加进一个 ShaderVariantCollection 挂到 `Graphics → Preloaded Shaders`(代价是包变大)。
- **任何 shader/材质/打包设置改动都只在重新打包后才进真机**——改完务必**干净重打 + 重装**(先卸旧包),别用旧 APK 验证。

## 2. 渠道 SDK / 编译宏 / 平台差异

详见 [TapTap 与广告 SDK 集成](../client/Docs/TapTap与广告SDK集成.md),这里只记最容易栽的点:

- **"装了 SDK 才开对应宏"**:`TAPTAP_LOGIN`/`TAPTAP_CLOUDSAVE`/`TAPTAP_LEADERBOARD`/`DIRICHLET_AD`。开了宏没装 SDK → 编译期 `CS0246`;没开宏 → Editor 走模拟、真机走"未接入"回退(**不报错但功能是假的**,容易误判)。
- **平台门控会让某服务"真机才存在"**:云存档同步 `CloudSaveSyncService` 只在 `#if UNITY_ANDROID && !UNITY_EDITOR` 注册;广告仅 `UNITY_ANDROID || UNITY_EDITOR`。Editor 取不到 = 正常,别误以为是 bug。
- **云存档 PC/Editor 必报 `Client ID 不存在`**:只能 Android 真机验证。
- **真机登录报"包名、签名错误"**:TapTap 后台要登记 `com.yoto.dalie` + 签名 MD5;**debug 签名每台机一份**,换机/正式包签名变了就登录失败。
- **Dirichlet `Samples/` 要删**:否则 AGP 拉旧 build-tools 报 "License not accepted";重新导包后再删一次。

## 3. 存档分槽(StoreMgr)

详见 [StoreManagerUsage](../client/Docs/StoreManagerUsage.md)。最隐蔽的几条:

- **启动必须激活某个槽并 `LoadAll`,否则大厅永远只显示"种子值"**:`Progress` 数据按 `slot{id}_` 前缀分槽落盘,槽=0(未激活)读写的是无前缀全局键。各系统 Init 时槽还是 0,改动落到 `slot{id}_` 文件却从不被读回 → 表现为"金币/体力/背包/装备都没保存"(假象)。入口见 `GameProjectBootstrapper.RunProjectStartup`。
- **`WhenSlotsReady` 前不能 `CreateSlot`/`DeleteSlot`**:槽清单异步读入,提前增删会和异步读回互相覆盖丢档。
- **可靠存档点是"面板关闭 / 关卡结束",不能只靠 `Shutdown`**:退出时写盘协程可能跑不完 → 丢档。`Shutdown` 里的 `Save` 仅尽力而为。

## 4. 网络层在本分支处于休眠

- `GameBootstrapper.BuildContext` 里 **Transport / Session / Lobby / Runtime 的注册被注释掉**,只有 `SteamPlatform`/`MainThreadDispatcher`/`MessageRegistry`/`MessageDispatcher`/序列化器在跑。
- 直接 `ctx.Get<INetworkSession>()` / `ctx.Get<ILobbyService>()` 会**抛异常**。要用先取消那几行注释并让 `NetworkRuntime.Tick` 驱动 `Poll()`。详见 [NetworkUsage](../client/Docs/NetworkUsage.md) 开头说明。
- (Steam)`SocketManager` override **必须调 `base`**,否则连接进不了 pollGroup,host 收不到任何包。

## 5. 配表 / 工具链

- **源表在 `tools/excel/3xlsx/`**(不是仓库根 `excel/`):animal/codex/currency/item/map/task。
- **发布前先关掉 Excel**,否则文件占用导致发布失败;一键发布 `tools/build_tables.bat` 或 `python tools/publish_config.py`。
- **protoc 版本对齐**:工具用 `tools/3rdparty/protobuf/protoc.exe`(3.6.1),runtime 用 `Plugins/Google.Protobuf`(3.21.12),升级要一起换。
- **`ScriptGenerated/` 与 `Resources/Config/Data/*.bytes` 禁止手改**,表头变了必须重发布。
- **`.meta` 必须随 `.cs`/资源一起提交**,漏了别人会 GUID 漂移(引用丢失,Inspector 变 Missing)。

## 6. Windows `.bat` 编码

- 给 cmd.exe 双击跑的 `.bat` **必须 CRLF 换行 + ASCII**。用 Write 工具默认写 LF / 含非 ASCII → 双击闪退或乱码。需要时用 PowerShell 强制 CRLF + ASCII 重写。

---

## 7. 服务注册顺序 / Init 取依赖

- **被依赖的服务必须先注册**(`Init` 按注册顺序、`Shutdown` 逆序)。`Init` 里 `ctx.Get<T>()` 硬取一个**后注册**的服务会抛异常。
- 典型补救:像 `WorldInteractionSystem.Init` 那样**先订阅关键输入(F 键),再 `TryGet` 其它服务**——即便后取的服务还没注册,关键订阅也已生效。需要后注册服务时在 `Tick` 里懒取。
