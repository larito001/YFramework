> 精简版：仅保留 **客户端配表读取 + C#代码生成 + Proto生成 + 二进制数据生成 + bat启动**。

## 一、整体架构

```
Excel (.xlsx)
    ↓
┌─ ExcelReader ──────────────────┐
│  读取表头元数据 (Row 1-5/6)    │
│  读取数据行 (Row 6/7+)         │
│  输出 ConfigData 对象          │
└────────────────────────────────┘
    ↓
┌─ splitConfig ──────────────────┐
│  按 colTarget 过滤仅客户端列   │
│  输出 clientConfig             │
└────────────────────────────────┘
    ↓
┌─ Writers ──────────────────────┐
│  ProtoWriter    → .proto 文件  │
│  ProtoDataWriter→ .bytes 文件  │
│  CSWriter       → .cs 文件     │
└────────────────────────────────┘
```

## 四、Excel 配置表格式规则

### 4.1 表头结构

| 行号 | 用途 | 示例 |
|------|------|------|
| **Row 1** | 列显示名 (colName) | `物品名称` / `稀有度` / `技能列表` |
| **Row 2** | 列标识符 (colID) | `item_name` / `rarity` / `skill_list` |
| **Row 3** | 数据类型 (colType) | `string` / `uint` / `array.int` |
| **Row 4** | 键与目标 (colTarget) | `client_key` / `all` / `client` / `main` / `child` |
| **Row 5** | 扩展标记（可忽略） | `text` / `term` / `len:100` (精简版不使用) |
| **Row 6** | 默认值 (colDefault) | 每列的默认值，空单元格用此值填充 |
| **Row 7+** | 数据行 | 实际配置数据 |

> **树形表**：如果 Row 4 中包含 `main` / `child` / `row`，则为树形表，默认值行改为 Row 7，数据从 Row 8 开始。

### 4.2 列检测终止规则

从 Row 2 逐列读取列 ID，遇到 **连续 10 个空列** 则认为表格结束。
数据行读取时，**一整行所有列都为空** 则停止。

### 4.3 数据类型系统

#### 基础类型

| 类型 | Python 转换 | 默认值 | 说明 |
|------|-------------|--------|------|
| `int` | `int(val)` | `-1` | 有符号32位整数 |
| `uint` | `int(val)` | `0` | 无符号32位整数 |
| `float` | `float(val)` | `0` | 32位浮点 |
| `bool` | `"true"→1, "false"→0` | `0` | 布尔值转为0/1 |
| `string` | `str(val)` | `""` | 文本 |

#### 复合类型

| 类型 | Excel 填写格式 | 分隔符 | 解析结果 | 默认值 |
|------|---------------|--------|---------|--------|
| `array.int` | `1\|2\|3` | `\|` | `[1, 2, 3]` | `[]` |
| `array.string` | `aaa\|bbb` | `\|` | `["aaa","bbb"]` | `[]` |
| `array.vec2.int` | `1~2\|3~4` | `\|` 分元素，`~` 分分量 | `[[1,2],[3,4]]` | `[]` |
| `vec2.int` | `100~200` | `~` | `[100, 200]` | `[0, 0]` |
| `vec2.float` | `1.5~2.5` | `~` | `[1.5, 2.5]` | `[0, 0]` |
| `vec3.int` | `1~2~3` | `~` | `[1, 2, 3]` | `[0, 0, 0]` |
| `vec3.float` | `1.0~2.0~3.0` | `~` | `[1.0, 2.0, 3.0]` | `[0, 0, 0]` |
| `map.string.int` | `atk~100\|def~50` | `\|` 分对，`~` 分KV | `{"atk":100,"def":50}` | `{}` |
| `map.string.float` | `speed~1.5\|hp~2.0` | `\|` 分对，`~` 分KV | `{"speed":1.5,"hp":2.0}` | `{}` |

> **Excel 中也支持分号写法**：map 类型中 `;` 会自动替换为 `|`，`=` 替换为 `~`；vec 类型中 `;` 替换为 `~`。

#### 类型合法性规则

```
合法类型 = 基础类型
         | array.{合法类型}
         | vec2.{基础类型}
         | vec3.{基础类型}
         | map.{基础类型}.{基础类型}
```

### 4.4 Row 4 目标与键标记

Row 4 的每列内容决定该列的**归属**和**索引角色**：

| 标记内容 | 含义 | 解析后 colTarget |
|---------|------|-----------------|
| `client` | 仅客户端 | `C` |
| `server` | 仅服务端（精简版跳过） | `S` |
| `all` | 客户端+服务端 | `CS` |
| `client_key` | 客户端列 + 作为索引键 | `C`，且加入 indexC |
| `all_key` | 双端列 + 作为索引键 | `CS`，且加入 indexC 和 indexS |
| `main` | 树形表主行标记 | 附加 `M` 标志 |
| `child` | 树形表子行标记 | 用于树形检测 |
| `rowkey` | 行号作为第二键 | ext 中附加 `R` |

**客户端过滤规则**：`splitConfig()` 时只保留 colTarget 中包含 `C` 的列。

### 4.5 索引（键）规则

- Row 4 中包含 `key` 的列成为索引字段
- **单键表**：只有一个 key 列 → `Dictionary<KeyType, ProtoClass>`
- **双键表**：有两个 key 列 → `Dictionary<Key1Type, Dictionary<Key2Type, ProtoClass>>`
- **双键行表**：第一个 key + `rowkey` 标记 → 第二键为自增 int（1-based）

### 4.6 树形表继承

当表被检测为树形表（Row 4 含 `main`/`child`/`row`）时：
- 标记了 `M`（main）的列：如果当前行该列为空，继承**上一行**同列的值
- 其他列为空时使用 Row 7 的默认值

### 4.7 示例表

| 物品名称 | 物品ID | 价格 | 标签列表 | 属性加成 |
|---------|--------|------|---------|---------|
| item_name | item_id | price | tag_list | attr_bonus |
| string | uint | int | array.string | map.string.int |
| client | client_key | all | client | client |
| | | | | |
| | 0 | 0 | | |
| 铁剑 | 1001 | 100 | weapon\|sword | atk~10\|def~5 |
| 木盾 | 1002 | 50 | shield | def~20 |

### 5.1 ConfigData.py — 数据模型

```python
# gtp/common/ConfigData.py

ARRAY_SEP = "|"
MAP_KEY_VAL_SEP = "~"
BASE_DATA_TYPE = ["int", "uint", "string", "float", "bool"]
COMPLEX_TYPE = ["map", "array", "vec2", "vec3"]


class ConfigData:
    def __init__(self):
        self.id = ""           # 表标识 (文件名，不含扩展名)
        self.name = ""         # 表名
        self.colID = []        # 列标识符列表
        self.colName = []      # 列显示名列表
        self.colType = []      # 列数据类型列表
        self.colTarget = []    # 列目标标记列表 (如 "C", "CS", "CLM")
        self.colDefault = []   # 列默认值列表
        self.dataIndex = []    # 索引字段组合 [[key1], [key1,key2]]
        self.dataIndexC = []   # 客户端索引
        self.data = []         # 数据行 [[val1, val2, ...], ...]
        self.ext = []          # 扩展标记 ("R" = rowkey)


def isValidType(typeStr):
    """校验类型字符串是否合法"""
    if typeStr in BASE_DATA_TYPE:
        return True
    items = typeStr.split(".")
    if len(items) <= 1:
        return False
    if items[0] == "array":
        return isValidType(typeStr[6:])
    if len(items) == 2 and items[0] in ["vec2", "vec3"] and items[1] in BASE_DATA_TYPE:
        return True
    if len(items) == 3 and items[0] == "map" and items[1] in BASE_DATA_TYPE and items[2] in BASE_DATA_TYPE:
        return True
    return False


def getDefaultValue(typeStr):
    """获取类型的默认值"""
    if typeStr == "int":
        return -1
    elif typeStr == "uint":
        return 0
    elif typeStr == "string":
        return ""
    elif typeStr == "float":
        return 0
    elif typeStr == "bool":
        return 0
    elif typeStr.startswith("array."):
        return []
    elif typeStr.startswith("vec2."):
        return [0, 0]
    elif typeStr.startswith("vec3."):
        return [0, 0, 0]
    elif typeStr.startswith("map."):
        return {}
    return None


def getPythonValue(val, typeStr, defaultVal):
    """将单元格值转为 Python 对象"""
    if val is None or (isinstance(val, str) and len(val) == 0):
        return defaultVal if defaultVal is not None else getDefaultValue(typeStr)

    if typeStr == "int":
        return int(val)
    elif typeStr == "uint":
        return int(val)
    elif typeStr == "string":
        return str(val)
    elif typeStr == "float":
        return float(val)
    elif typeStr == "bool":
        s = str(val).lower()
        if s == "true":
            return 1
        if s == "false":
            return 0
        return int(val)

    elif typeStr.startswith("array."):
        valType = typeStr[6:]
        vals = str(val).split(ARRAY_SEP)
        return [getPythonValue(v, valType, None) for v in vals]

    elif typeStr.startswith("vec2."):
        val = str(val).strip()
        if val == "0":
            return [0, 0]
        valType = typeStr[5:]
        vals = val.split("~")
        r = [getPythonValue(v, valType, None) for v in vals]
        if len(r) != 2:
            raise Exception("vec2 需要恰好2个分量: " + val)
        return r

    elif typeStr.startswith("vec3."):
        val = str(val).strip()
        if val == "0":
            return [0, 0, 0]
        valType = typeStr[5:]
        vals = val.split("~")
        r = [getPythonValue(v, valType, None) for v in vals]
        if len(r) != 3:
            raise Exception("vec3 需要恰好3个分量: " + val)
        return r

    elif typeStr.startswith("map."):
        val = str(val).strip()
        if val == "0":
            return {}
        typeStrs = typeStr.split(".")  # ["map", keyType, valType]
        vals = val.split(ARRAY_SEP)
        r = {}
        for pair in vals:
            if pair.strip():
                kvs = pair.split("~")
                r[kvs[0]] = getPythonValue(kvs[1], typeStrs[2], None)
        return r

    raise Exception("未知类型: " + typeStr)


def splitConfigClient(data):
    """从完整 ConfigData 中提取仅客户端列，返回新的 ConfigData"""
    client = ConfigData()
    client.id = data.id
    client.name = data.name
    client.ext = data.ext

    colCount = len(data.colID)

    # 过滤列：仅保留 colTarget 含 "C" 的列
    clientColIndices = []
    for i in range(colCount):
        if "C" in data.colTarget[i]:
            clientColIndices.append(i)
            client.colID.append(data.colID[i])
            client.colName.append(data.colName[i])
            client.colType.append(data.colType[i])
            client.colTarget.append(data.colTarget[i])
            client.colDefault.append(data.colDefault[i])

    # 过滤数据行
    for row in data.data:
        client.data.append([row[i] for i in clientColIndices])

    # 过滤索引：仅保留所有键列都存在于客户端列中的索引
    for idx in data.dataIndex:
        if all(k in client.colID for k in idx):
            client.dataIndex.append(idx)
    for idx in data.dataIndexC:
        client.dataIndex.append(idx)

    return client
```

### 5.2 ExcelReader.py — 读取 Excel

```python
# gtp/reader/ExcelReader.py

import openpyxl
import os
from gtp.common.ConfigData import (
    ConfigData, isValidType, getPythonValue, ARRAY_SEP
)


def _getStdType(typeStr):
    """标准化类型字符串"""
    typeStr = (typeStr.lower().strip()
               .replace("_", ".")
               .replace("dictionary", "map")
               .replace("vector2", "vec2")
               .replace("vector3", "vec3")
               .replace("vec3.array", "array.vec3")
               .replace("vec2.array", "array.vec2"))
    if isValidType(typeStr):
        return typeStr
    raise Exception("无效的数据类型: " + typeStr)


def _getStdTarget(targetStr):
    """将 Row4 目标文本转为缩写"""
    targetStr = targetStr.lower().strip()
    if "server" in targetStr:
        return "S"
    elif "client" in targetStr:
        return "C"
    elif "all" in targetStr:
        return "CS"
    return ""


def readExcel(path):
    """
    读取一个 Excel 配置表，返回 ConfigData 对象。
    行结构：
      Row 1 = 列显示名, Row 2 = 列ID, Row 3 = 类型,
      Row 4 = 目标/键, Row 5 = 扩展(忽略),
      Row 6 = 默认值, Row 7+ = 数据
    树形表：Row 7 = 默认值, Row 8+ = 数据
    """
    wb = openpyxl.load_workbook(filename=path, read_only=True, data_only=True)
    st = wb.worksheets[0]
    r = ConfigData()
    r.id = os.path.splitext(os.path.basename(path))[0]
    r.name = r.id

    # ---- 1. 列检测 (Row 2) ----
    cells = st[2]
    detectionCount = 10
    noneCount = 0
    cellIndex = 1
    mapTables = {}  # {colSeq(str): actual_excel_column(int)}

    for tmpcell in cells:
        if tmpcell.data_type == 's':
            noneCount = 0
            cellVal = tmpcell.value.strip()
            if cellVal != "":
                r.colID.append(cellVal)
                mapTables[str(len(r.colID))] = cellIndex
            else:
                break
        else:
            noneCount += 1
            if noneCount == detectionCount:
                break
        cellIndex += 1

    colCount = len(r.colID)
    if colCount == 0:
        wb.close()
        return None

    # ---- 2. 读取列元数据 ----
    indexC = []
    isTree = False

    for colIndex in range(1, colCount + 1):
        curCol = mapTables[str(colIndex)]

        # Row 1: 列名
        r.colName.append(str(st.cell(row=1, column=curCol).value or "").strip())

        # Row 3: 类型
        typeStr = str(st.cell(row=3, column=curCol).value or "").strip()
        r.colType.append(_getStdType(typeStr))

        # Row 4: 目标+键
        row4Str = str(st.cell(row=4, column=curCol).value or "").strip()

        extraFlag = ""
        if "main" in row4Str:
            extraFlag += "M"

        target = _getStdTarget(row4Str)
        r.colTarget.append(target + extraFlag)

        if "rowkey" in row4Str:
            r.ext.append("R")

        # 索引收集：仅客户端
        if "key" in row4Str:
            if "all" in row4Str or "client" in row4Str:
                indexC.append(r.colID[colIndex - 1])

        # 树形检测
        if "main" in row4Str or "child" in row4Str or "row" in row4Str:
            isTree = True

    if len(indexC) > 0:
        r.dataIndexC.append(indexC)

    # ---- 3. 读取默认值 ----
    defaultRow = 6
    for colIndex in range(1, colCount + 1):
        curCol = mapTables[str(colIndex)]
        cell = st.cell(row=defaultRow, column=curCol)

        # 树形表：Row 7 可覆盖 Row 6
        if isTree:
            cell2 = st.cell(row=7, column=curCol)
            if cell2.value is not None:
                cell = cell2

        colType = r.colType[colIndex - 1]
        cellVal = cell.value

        # 分隔符替换
        if cellVal is not None and isinstance(cellVal, str):
            if "map" in colType:
                cellVal = cellVal.replace(";", ARRAY_SEP).replace("=", "~")
            elif "vec" in colType:
                cellVal = cellVal.replace(";", "~")

        r.colDefault.append(getPythonValue(cellVal, colType, None))

    # ---- 4. 读取数据行 ----
    startRow = 7 if not isTree else 8
    rowIndex = 0
    lastRowData = None

    for row in st.rows:
        rowIndex += 1
        if len(row) == 0:
            break
        if rowIndex < startRow:
            continue

        rowData = []
        nullCount = 0

        for colIndex in range(1, colCount + 1):
            curCol = mapTables[str(colIndex)]
            cell = row[curCol - 1]
            cellVal = cell.value

            if cellVal is None:
                nullCount += 1

            colType = r.colType[colIndex - 1]

            # 分隔符替换
            if cellVal is not None and isinstance(cellVal, str):
                if "map" in colType:
                    cellVal = cellVal.replace(";", ARRAY_SEP).replace("=", "~")
                elif "vec" in colType:
                    cellVal = cellVal.replace(";", "~")

            # 树形继承
            if isTree and "M" in r.colTarget[colIndex - 1] and lastRowData is not None:
                rowData.append(getPythonValue(cellVal, colType, lastRowData[colIndex - 1]))
            else:
                rowData.append(getPythonValue(cellVal, colType, r.colDefault[colIndex - 1]))

        if nullCount >= colCount:
            break

        r.data.append(rowData)
        lastRowData = rowData

    wb.close()
    return r
```

```python
# gtp/writer/ProtoHelper.py

# 配置类型 → Proto 类型
type_map = {
    "uint":              "uint32",
    "int":               "int32",
    "bool":              "int32",
    "string":            "string",
    "float":             "float",
    "vec2.int":          "Vector2Int",
    "vec2.float":        "Vector2Float",
    "vec3.int":          "Vector3Int",
    "vec3.float":        "Vector3Float",
    "array.uint":        "uint32",
    "array.int":         "int32",
    "array.float":       "float",
    "array.string":      "string",
    "array.bool":        "int32",
    "array.vec2.int":    "Vector2Int",
    "array.vec2.float":  "Vector2Float",
    "array.vec3.int":    "Vector3Int",
    "array.vec3.float":  "Vector3Float",
    "map.string.int":    "KeyValuePairStrInt",
    "map.string.float":  "KeyValuePairStrFloat",
}


def getProtoType(typeStr):
    """返回 proto 字段类型"""
    return type_map.get(typeStr, typeStr)


def getProtoRule(typeStr):
    """返回 proto 字段规则：array/map 用 repeated，其余 optional"""
    if "array" in typeStr or "map" in typeStr:
        return "repeated"
    return "optional"
```

### 5.4 ProtoWriter.py — 生成 .proto 文件

```python
# gtp/writer/ProtoWriter.py

from gtp.writer import ProtoHelper

# ---- 基础类型定义（只需生成一次） ----
PROTO_BASE_TYPES = '''/**
 * Generated By Tool, DO NOT MODIFY.
**/
syntax = "proto2";
package com.youzu.got.config;

message Vector2Int {
  optional int32 x = 1;
  optional int32 y = 2;
}
message Vector3Int {
  optional int32 x = 1;
  optional int32 y = 2;
  optional int32 z = 3;
}
message Vector2Float {
  optional float x = 1;
  optional float y = 2;
}
message Vector3Float {
  optional float x = 1;
  optional float y = 2;
  optional float z = 3;
}
message KeyValuePairStrInt {
  optional string k = 1;
  optional int32 v = 2;
}
message KeyValuePairStrFloat {
  optional string k = 1;
  optional float v = 2;
}

// ---- Header 索引类型（用于新版懒加载） ----
message IndexInt {
  optional int32 id = 1;
  optional int32 offset = 2;
}
message ConfigIntHeader {
  repeated IndexInt headers = 1;
}
message IndexUint {
  optional uint32 id = 1;
  optional int32 offset = 2;
}
message ConfigUintHeader {
  repeated IndexUint headers = 1;
}
message IndexStr {
  optional string id = 1;
  optional int32 offset = 2;
}
message ConfigStringHeader {
  repeated IndexStr headers = 1;
}
'''


def writeBaseTypes(path):
    """生成 ConfigBaseType.proto"""
    with open(path, 'w', encoding='utf-8') as f:
        f.write(PROTO_BASE_TYPES)


def writeData(path, data):
    """为一张配置表生成 .proto 文件"""
    colCount = len(data.colID)
    if colCount <= 0:
        return False

    className = data.id[0].upper() + data.id[1:]
    package = "com.youzu.got.config"

    lines = []
    lines.append('/**\n * Generated by tools, don\'t modify!\n**/')
    lines.append('syntax = "proto2";')
    lines.append('package %s;\n' % package)
    lines.append('import "ConfigBaseType.proto";\n')
    lines.append('message %s {' % className)

    for i in range(colCount):
        rule = ProtoHelper.getProtoRule(data.colType[i])
        ptype = ProtoHelper.getProtoType(data.colType[i])
        lines.append('  %s %s %s = %d; //%s' % (
            rule, ptype, data.colID[i], i + 1, data.colName[i]
        ))

    lines.append('}\n')

    # LIST 包装消息（用于序列化整张表）
    lines.append('message %s_LIST_TOOL_RESERVED {' % className)
    lines.append('  repeated %s items = 1;' % className)
```

### 5.5 ProtoDataWriter.py — 生成 .bytes 二进制数据

```python
# gtp/writer/ProtoDataWriter.py

import struct
import importlib
from io import BytesIO
from gtp.writer import ProtoHelper


def _getProtoValue(fieldType, cellVal, isRepeated=False):
    """将 Python 值转为 proto 可赋值的对象"""
    # 需要先用 protoc 编译 .proto 生成 _pb2.py，然后 import 使用
    # 这里给出逻辑伪代码，实际使用需要 import 对应的 pb2 模块
    pass


def writeData(path, data, pb2_module):
    """
    将 ConfigData 序列化为 .bytes 二进制文件。

    文件格式 (大端序)：
    ┌──────────────────────────────────────┐
    │ 2 bytes: mainKeyCount (uint16 BE)    │
    │ 2 bytes: headerCount  (uint16 BE)    │
    │ 4 bytes: headerLength (uint32 BE)    │
    │ [headerLength bytes: ConfigHeader]   │
    │ [Entry1: 2B长度 + protobuf二进制]     │
    │ [Entry2: 2B长度 + protobuf二进制]     │
    │ ...                                  │
    └──────────────────────────────────────┘

    每条 Entry 的偏移量记录在 Header 中，
    C# 读取时 Seek 位置 = headerLength + 8 + header.offset
    """
    className = data.id[0].upper() + data.id[1:]
    colCount = len(data.colID)
    rowCount = len(data.data)

    if colCount <= 0 or rowCount <= 0:
        return False

    # 获取 pb2 模块中的消息类
    ItemClass = getattr(pb2_module, className)
    ListClass = getattr(pb2_module, className + "_LIST_TOOL_RESERVED")

    # 确定主键列索引
    mainKeyCol = data.colID.index(data.dataIndex[0][0]) if data.dataIndex else 0
    subKeyCol = None
    if data.dataIndex and len(data.dataIndex[0]) > 1:
        subKeyCol = data.colID.index(data.dataIndex[0][1])

    # ---- Stage 1: 序列化每条数据 ----
    entries_buffer = BytesIO()
    offsets = []

    for rowIdx in range(rowCount):
        row = data.data[rowIdx]
        item = ItemClass()

        for colIdx in range(colCount):
            cellVal = row[colIdx]
            if cellVal is None:
                continue

            fieldName = data.colID[colIdx]
            fieldRule = ProtoHelper.getProtoRule(data.colType[colIdx])
            fieldType = ProtoHelper.getProtoType(data.colType[colIdx])

            # 根据 fieldRule 和 fieldType 设置字段值
            # (简化示意，实际需要处理 Vector/KVP 等复合类型)
            if fieldRule == "repeated":
                if isinstance(cellVal, list):
                    getattr(item, fieldName).extend(cellVal)
                elif isinstance(cellVal, dict):
                    # map 类型: 转为 repeated KVP
                    KVPClass = getattr(pb2_module, fieldType)
                    for k, v in cellVal.items():
                        kvp = KVPClass()
                        kvp.k = k
                        kvp.v = v
                        getattr(item, fieldName).append(kvp)
            else:
                if fieldType in ("Vector2Int", "Vector2Float"):
                    field = getattr(item, fieldName)
                    field.x = cellVal[0]
                    field.y = cellVal[1]
                elif fieldType in ("Vector3Int", "Vector3Float"):
                    field = getattr(item, fieldName)
                    field.x = cellVal[0]
                    field.y = cellVal[1]
                    field.z = cellVal[2]
                else:
                    setattr(item, fieldName, cellVal)

        entry_bytes = item.SerializeToString()
        entry_len = len(entry_bytes)
        if entry_len > 0xFFFF:
            raise Exception("单条数据超过 65535 字节限制")

        offsets.append(entries_buffer.tell())
        entries_buffer.write(struct.pack('>H', entry_len))
        entries_buffer.write(entry_bytes)

    # ---- Stage 2: 生成 Header ----
    # (根据主键类型选择对应的 Header 消息类型)
    mainKeyType = ProtoHelper.getProtoType(data.colType[mainKeyCol])
    headerClassName = "Config" + mainKeyType.replace("32", "").capitalize() + "Header"
    HeaderClass = getattr(pb2_module, headerClassName, None)

    # 如果 pb2 中没有对应的 Header 类，使用 LIST 模式 (旧版兼容)
    if HeaderClass is None:
        # 旧版：直接序列化整个列表
        listObj = ListClass()
        for rowIdx in range(rowCount):
            row = data.data[rowIdx]
            item = listObj.items.add()
            # ... 填充字段 (同上)
        with open(path, 'wb') as f:
            f.write(listObj.SerializeToString())
        return True

    config_header = HeaderClass()
    mainKeyCount = 0
    mainKeyDict = {}

    for rowIdx in range(rowCount):
        row = data.data[rowIdx]
        entry = config_header.headers.add()
        entry.id = row[mainKeyCol]
        if subKeyCol is not None:
            entry.subId = row[subKeyCol]
            if entry.id not in mainKeyDict:
                mainKeyDict[entry.id] = True
                mainKeyCount += 1
        else:
            mainKeyCount += 1
        entry.offset = offsets[rowIdx]

    # ---- Stage 3: 写入文件 ----
    header_bytes = config_header.SerializeToString()
    header_length = len(header_bytes)
    header_count = len(config_header.headers)

    with open(path, 'wb') as f:
        f.write(struct.pack('>H', mainKeyCount))
        f.write(struct.pack('>H', header_count))
        f.write(struct.pack('>I', header_length))
        f.write(header_bytes)
        f.write(entries_buffer.getvalue())

    return True
```

```python
        return False

    fmt = {
        "namespace":    NAMESPACE,
        "configClass":  protoClass + "Config",
        "configVar":    data.id[0].lower() + data.id[1:] + "Config",
        "protoClass":   protoClass,
        "managerClass": MANAGER_CLASS,
        "bytesName":    protoClass,
    }

            content = TEMPLATE_DOUBLE_KEY_ROW.format(**fmt)
        else:
            # Tree 模式
            fmt["subclass"] = TEMPLATE_DOUBLE_KEY_CLASS.format(**fmt)
            content = TEMPLATE_DOUBLE_KEY_TREE.format(**fmt)

    with open(path, 'w', encoding='utf-8') as f:
        f.write(content)
    return True
```

```python
# publish_config.py

import os
import sys
import configparser
from gtp.common.ConfigData import splitConfigClient
from gtp.reader.ExcelReader import readExcel
from gtp.writer import ProtoWriter, CSWriter


def loadConfig():
    """从 tools_config.ini 加载路径配置"""
    config = configparser.ConfigParser()
    config.read("tools_config.ini", encoding="utf-8")
    return {
        "config_dir":  config.get("path", "config_dir"),
        "client_dir":  config.get("path", "client_dir"),
        "proto_dir":   config.get("path", "proto_dir"),
    }


def publishFile(filePath, cfg):
    """发布单个 Excel 配置文件"""
    fileID = os.path.splitext(os.path.basename(filePath))[0]
    print("Publishing: " + fileID)

    # 1. 读取 Excel
    rawData = readExcel(filePath)
    if rawData is None:
        print("  Skip (no data): " + fileID)
        return False

    # 2. 仅保留客户端列
    clientData = splitConfigClient(rawData)
    if len(clientData.colID) == 0 or len(clientData.dataIndex) == 0:
        print("  Skip (no client columns): " + fileID)
        return False

    className = fileID[0].upper() + fileID[1:]

    # 3. 生成 .proto
    protoPath = os.path.join(cfg["proto_dir"], fileID + ".proto")
    ProtoWriter.writeData(protoPath, clientData)
    print("  -> " + protoPath)

    # 4. 生成 .cs
    csPath = os.path.join(cfg["client_dir"], "ScriptGenerated", "Config", className + "Config.cs")
    os.makedirs(os.path.dirname(csPath), exist_ok=True)
    CSWriter.writeData(csPath, clientData)
    print("  -> " + csPath)

    # 5. 编译 proto 并生成 .bytes (需要 protoc + pb2 模块)
    #    此处需要先运行 protoc 编译 .proto → _pb2.py
    #    然后 import pb2 模块并调用 ProtoDataWriter.writeData()
    #    具体流程见第七节

    return True


def publishAll(cfg):
    """遍历目录发布所有 Excel 文件"""
    configDir = os.path.join(cfg["config_dir"], "3xlsx")
    count = 0

    for root, dirs, files in os.walk(configDir):
        # 跳过 _temp 目录
        dirs[:] = [d for d in dirs if d != "_temp"]

        for f in files:
            ext = os.path.splitext(f)[1].lower()
            if ext not in (".xls", ".xlsx", ".xlsm"):
                continue
            if "~" in f or "$" in f:
                continue  # 跳过临时文件

            filePath = os.path.join(root, f)
            if publishFile(filePath, cfg):
                count += 1

    print("\nDone. Published %d files." % count)


if __name__ == "__main__":
    cfg = loadConfig()

    # 确保输出目录存在
    os.makedirs(cfg["proto_dir"], exist_ok=True)

    if len(sys.argv) > 1:
        # 发布指定文件
        for path in sys.argv[1:]:
            publishFile(path, cfg)
    else:
        # 发布全部
        publishAll(cfg)
```

```python
import subprocess

def compileProto(protoDir, outputDir, protocPath):
```
