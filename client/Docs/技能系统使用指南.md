# 技能系统使用指南（SkillDef + SkillCastComponent）

> 本文是**使用文档**（怎么做技能、怎么触发、怎么调参）。技能系统在整体架构里的**结构与职责划分**见 `Assets/Scripts/GamePlay/TPS/ARCHITECTURE.md` 的"技能系统"小节。

技能 = 玩家近战 / 僵尸攻击·飞扑 等**全身、不可打断、带伤害的动作**。一个技能就是一个 **`SkillDef` ScriptableObject 资产**，**纯 Inspector 编辑，不写代码**。运行时由 `SkillCastComponent`（逻辑组件）驱动：推进分段时间线、命中窗扣血、按段位移、锁定角色、把当前段 clip 交给动画 controller 播放。

---

## 一、新建一个技能

1. Project 窗口 → Create → **TPS → SkillDef**。
2. 放到 **`Assets/Resources/Skill/`** 下（如 `Resources/Skill/PlayerMelee.asset`）——必须在 `Resources` 里，`SkillCastComponent` 按 Resources 相对路径加载。
3. 填顶层字段：
   - **`Name`**：编辑器可读标识（如 `PlayerMelee` / `ZombieLeap`）。
   - **`RecoverFade`**：整技能放完回 locomotion（idle/走/跑）的淡入时长（秒）。0 = 用 `CharacterAnimSet.DefaultFade`。
4. 配 **`Segments`**（按顺序播放的段，每段一个全身 clip）。
5. 把 Resources 相对路径配到持有者的 **`SkillCastComponent.SkillPaths`**（程序员在 Factory 里配；数组下标即触发用的技能索引）。

---

## 二、Segment（段）字段

| 字段 | 含义 |
|---|---|
| `Clip` | 本段全身动画。 |
| `Fade` | 进入本段的淡入时长（秒）。0=用 DefaultFade；**段间衔接**一般填 0~0.1 紧凑。 |
| `HoldDuration` | 段持续策略：**0** = 播到 clip 自然结束（按 `clip.length`）；**>0** = 循环该 clip 这么多秒再进下一段。⚠️ 循环段的 clip 必须在 **fbx import 勾 Loop Time**，否则播一遍就停。 |
| `ForwardDistance` | 本段沿角色前向的总位移（米）。**0**=原地（攻击）；**正**=前冲（飞扑 Air 段填大值如 4）；**负**=后退。位移走 `WishVelocity` + CharacterController，撞墙/贴地正确。 |
| `DistanceProfile` | 位移随段内进度的分布曲线（x=段进度 0→1，y=已位移占比 0→1）。留空=线性匀速。可做"前段爆发、后段刹车"。 |
| `HitWindows` | 本段的命中窗数组（可多个，做多段连击伤害）。见下。 |

### HitWindow（命中窗）字段

| 字段 | 含义 |
|---|---|
| `StartNorm` / `EndNorm` | 段内**归一化时间** [0,1] 开/关伤害检测——对齐 clip 的实际命中帧。 |
| `Radius` / `ForwardOffset` / `Height` | 球形 hitbox：中心 = 角色脚下 `Position` + 前向×`ForwardOffset` + 上×`Height`，半径 `Radius`。 |
| `Damage` | 伤害配方 `DamageSpec`：基础伤害 / 卡肉 `HitstopTier` / 暴击概率·倍率 / 元素 / 携带 buff。 |

> 同一命中窗内对同一目标只扣一次（去重）。多段各自的命中窗独立去重——连招里每段都能再打到同一目标。
> ⚠️ **同一段内的多个命中窗不要在时间上重叠**：当前实现按数组顺序取第一个命中 `n` 的窗，重叠时只有靠前的生效。把它们排成不重叠的时间区间。

## 三、触发

技能由**输入组件**（`InputComponentBase`）的 `OnCastSkill(int 下标)` 事件触发，`SkillCastComponent` 订阅它：

- **玩家**：`InputComponent` 在 V 键（`InputService.OnMeleeDown`）时 `RaiseCastSkill(0)` → 释放 `SkillPaths[0]`。
- **AI / 僵尸**：`AIInputComponent`（或真行为树）`RaiseCastSkill(i)` → 释放 `SkillPaths[i]`。
- **代码直触**：`actor.Get<SkillCastComponent>().Cast(i)`。

> 输入与玩法解耦：玩家走 `InputComponent`、AI 走 `AIInputComponent`，下游 SkillCastComponent 完全相同。详见 ARCHITECTURE 的"输入抽象层"。

**不可打断**：释放途中移动 / 转身 / 开火 / 换弹 / 切枪 / 再次触发**全部被 `Character.IsCastingSkill` 锁住**；已在释放中时新的 `Cast` 被静默忽略。技能放完才解锁。

## 四、配置范例

| 形态 | Segments 排法 |
|---|---|
| 单段攻击 | `[ Atk(HitWindow 命中帧) ]`，ForwardDistance=0 |
| 起手→循环→收招 | `[ Stand_To_Atk, Atk_Loop(HoldDuration=N, HitWindow), Atk_End ]` |
| 连招（多段伤害） | `[ Hard(HitWindow), Kick(HitWindow) ]`（玩家近战即此，一次按键放完两段） |
| 飞扑 | `[ Jump_Start, Jump_Air(ForwardDistance 大), Jump_End(落地命中窗) ]` |

## 五、一键生成现有技能资产

菜单 **Tools/TPS → Build Skill & Anim Assets**（`Assets/Scripts/Editor/Animation/ZombieAssetBuilder.cs`）从真实 fbx clip **程序化生成**到 `Resources/`：

- `Resources/Zombie/ZombieAnimSet.asset`（僵尸 locomotion + 死亡）
- `Resources/Skill/ZombieAttack.asset`、`ZombieLeap.asset`
- `Resources/Skill/PlayerMelee.asset`（Hard→Kick 两段连招）

并自动给 locomotion / 循环段 clip 的 fbx 设 `Loop Time`。

要改数值/段：**直接改生成的 `.asset`**（Inspector）即可；或改 `ZombieAssetBuilder.cs` 后重跑菜单（会覆盖重建）。
