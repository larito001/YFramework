# 技能 / 连招系统使用指南（SkillDef · ComboGraph · 取消窗 · 近战吸附）

> 本文是**使用文档**（怎么做技能/连招、怎么触发、怎么调参）。在整体架构里的**结构与职责划分**见 `Assets/Scripts/GamePlay/TPS/ARCHITECTURE.md` 的"技能系统 / 连招系统"小节。

技能 = 玩家近战 / 僵尸攻击·飞扑 等**全身、带伤害的动作**。一个技能就是一个 **`SkillDef` ScriptableObject 资产**，**纯 Inspector 编辑，不写代码**。运行时由 `SkillCastComponent`（逻辑组件）驱动：推进分段时间线、命中窗扣血、按段位移、近战吸附、取消窗、把当前段 clip 交给动画 controller 播放。

多个 `SkillDef` 可由 **`ComboGraph`** 编排成**连招**（按键接续、分支），由 **`ComboComponent`** 驱动。先看一~四（单招），连招看五，吸附看六。

> **本文覆盖**：① `SkillDef`（一招的数据）② 取消窗（后摇可被连招/移动取消）③ `ComboGraph`+`ComboComponent`（连招编排）④ 近战吸附。

---

## 一、新建一个技能

1. Project 窗口 → Create → **TPS → SkillDef**。
2. 放到 **`Assets/Resources/Skill/`** 下（如 `Resources/Skill/PlayerMelee.asset`）——必须在 `Resources` 里，`SkillCastComponent` 按 Resources 相对路径加载。
3. 填顶层字段：
   - **`Name`**：编辑器可读标识（如 `PlayerMelee` / `ZombieLeap`）。
   - **`RecoverFade`**：整技能放完回 locomotion（idle/走/跑）的淡入时长（秒）。0 = 用 `CharacterAnimSet.DefaultFade`。
4. 配 **`Segments`**（按顺序播放的段，每段一个全身 clip）。
5. 把 Resources 相对路径配到持有者的 **`SkillCastComponent.SkillPaths`**（程序员在 Factory 里配；数组下标即触发用的技能索引）。

## 二、Segment（段）字段

| 字段 | 含义 |
|---|---|
| `Clip` | 本段全身动画。 |
| `Fade` | 进入本段的淡入时长（秒）。0=用 DefaultFade；**段间衔接**一般填 0~0.1 紧凑。 |
| `HoldDuration` | 段持续策略：**0** = 播到 clip 自然结束（按 `clip.length`）；**>0** = 循环该 clip 这么多秒再进下一段。⚠️ 循环段的 clip 必须在 **fbx import 勾 Loop Time**，否则播一遍就停。 |
| `CancelFromNorm` | **取消窗**开启的归一化时间 [0,1]：到此之后本段可被**再次攻击**打断、接下一招（连招）。**1 或 0 = 不开窗**（默认，后摇不可取消，全程不可打断）。⚠️ **必须 ≥ 本段所有 `HitWindow.EndNorm`**，否则连招会吃掉命中帧。例：命中在 0.45 结束，填 0.5 → 0.5 之后可被连招打断。详见"五、连招系统"。 |
| `MoveCancelable` | 是否允许**移动**取消本段收招（进入取消窗后玩家一有移动意图就 `EndCast` 脱离去走位）。**默认 false**——避免和连招抢取消窗（边走边连招时不被走位掐断）。仅给"想用移动主动脱后摇"的招（如某些重攻击）开；连招招式保持 false，靠"再次攻击"接续。 |
| `ForwardDistance` | 本段沿角色前向的总位移（米）。**0**=原地（攻击）；**正**=前冲（飞扑 Air 段填大值如 4）；**负**=后退。位移走 `WishVelocity` + CharacterController，撞墙/贴地正确。开了近战吸附时正值会被吸附主动收敛到目标身前（见"六、近战吸附"），0/负值仍按原值。 |
| `DistanceProfile` | 位移随段内进度的分布曲线（x=段进度 0→1，y=已位移占比 0→1）。留空=线性匀速。可做"前段爆发、后段刹车"。 |
| `HitWindows` | 本段的命中窗数组（可多个，做多段连击伤害）。见下。 |
| `Vfx` | 本段的动效数组（可多个）。每个动效到段内归一化时间 `StartNorm` 生成一个特效 prefab（`Path` 为 Resources 相对路径）：`AttachToOwner=false` 生成在世界点不跟随（命中爆点/挥砍残影），`true` 挂角色身上跟随、到 `EndNorm` 销毁（光环/充能）。可配 `LocalOffset`/`RotationEuler`/`Scale`。 |
| `Shake` | 本段的相机震屏数组（可多个）。每项到段内 `StartNorm` 触发一次 kickback 震屏（相机往技能反向顿一下），按 `Intensity`（强度，默认 0.18）/ `Duration`（衰减秒，默认 0.15）衰减。 |

### HitWindow（命中窗）字段

| 字段 | 含义 |
|---|---|
| `StartNorm` / `EndNorm` | 段内**归一化时间** [0,1] 开/关伤害检测——对齐 clip 的实际命中帧。 |
| `Radius` / `ForwardOffset` / `Height` | 球形 hitbox：中心 = 角色脚下 `Position` + 前向×`ForwardOffset` + 上×`Height`，半径 `Radius`。 |
| `Damage` | 伤害配方 `DamageSpec`：基础伤害 / 卡肉 `HitstopTier` / 暴击概率·倍率 / 元素 / 携带 buff。 |

> 同一命中窗内对同一目标只扣一次（去重）。多段各自的命中窗独立去重——连招里每段都能再打到同一目标。
> ⚠️ **同一段内的多个命中窗不要在时间上重叠**：当前实现按数组顺序取第一个命中 `n` 的窗，重叠时只有靠前的生效。把它们排成不重叠的时间区间。

## 三、触发

`SkillCastComponent` 的入口是 `Cast(int 下标)` / `Cast(SkillDef)`。**谁来调它分两条路**：

- **AI / 僵尸**：`AIInputComponent`（或真行为树）`RaiseCastSkill(i)` → `InputComponentBase.OnCastSkill` 事件 → `SkillCastComponent` 直接订阅 → 释放 `SkillPaths[i]`。
- **玩家**：左键 / V 不再直发技能，而是发**语义攻击键**（`InputComponentBase.OnAttack`：左键=Light、V=Heavy）→ **`ComboComponent`**（连招前端）按当前武器的连招图把它路由成具体 `SkillDef` → `Cast(SkillDef)`。详见"五、连招系统"。
- **代码直触**：`actor.Get<SkillCastComponent>().Cast(i)`。

> 输入与玩法解耦：玩家走 `InputComponent`→`ComboComponent`、AI 走 `AIInputComponent`，下游 SkillCastComponent 完全相同。详见 ARCHITECTURE 的"输入抽象层"。

### 取消 / 不可打断

释放途中移动 / 转身 / 开火 / 换弹 / 切枪默认全被 `Character.IsCastingSkill` 锁住。**收招（后摇）能否被取消，由本段 `CancelFromNorm` 决定**：

- `CancelFromNorm = 1`（默认）→ 全程不可打断，播完整段才解锁（**旧行为**，PlayerMelee / 僵尸技能都是这样）。
- `CancelFromNorm < 1` → 到该归一化时间后开**取消窗**：
  - **再次攻击** → 打断当前招、接下一招（连招，见"五"）。窗内 `Cast` 不再被忽略。
  - **移动** → 仅当本段 `MoveCancelable=true` 才提前 `EndCast` 脱离去走位（默认 false，不和连招抢窗）。
  - **无任何输入** → 照常播完整段（完整后摇），不会被自动砍。

## 四、配置范例

| 形态 | Segments 排法 |
|---|---|
| 单段攻击 | `[ Atk(HitWindow 命中帧) ]`，ForwardDistance=0 |
| 起手→循环→收招 | `[ Stand_To_Atk, Atk_Loop(HoldDuration=N, HitWindow), Atk_End ]` |
| 招内多段（一次触发放完） | `[ Hard(HitWindow), Kick(HitWindow) ]`（多段一次性放完、不可打断；与"连招"不同——连招是多个**独立 SkillDef** 按键接续） |
| 飞扑 | `[ Jump_Start, Jump_Air(ForwardDistance 大), Jump_End(落地命中窗) ]` |
| 连招里的一招 | 单段 `[ Atk(HitWindow) ]`，`CancelFromNorm` 配在命中后（如 0.5）→ 进招式图当节点（见"五"） |

## 五、连招系统（ComboGraph + ComboComponent）

把"一招"（`SkillDef`）编排成**有向图**：节点 = 一招，边 = "在某招取消窗内、按某键（+可选方向）→ 跳到下一招"。一套连招 = 一个 **`ComboGraph` ScriptableObject 资产**，纯 Inspector 配。运行时由 **`ComboComponent`**（Character 侧逻辑组件）驱动，每招的执行/位移/命中/取消窗仍归 `SkillCastComponent`。

### 做一套连招（3 步）

1. **造招**：每一击做一个**独立单段 `SkillDef`**（Atk1/Atk2/Atk3…），每个把 `CancelFromNorm` 配在命中之后（如 0.5），`MoveCancelable` 留 false。
2. **连图**：Create → **TPS → ComboGraph**，放 Resources。配 `Nodes`，约定 **`[0]=Neutral` 入口**（Skill 留空，Links 为各键起手招）：
   ```
   [0] Neutral  Skill=∅          Links={ (Light→1), (Heavy→4) }
   [1] Atk1     Skill=Knife_Atk1  Links={ (Light→2) }
   [2] Atk2     Skill=Knife_Atk2  Links={ (Light→3), (Heavy→4) }   // 轻轻轻=三连；轻轻重=重击收尾
   [3] Atk3     Skill=Knife_Atk3  Links={}                          // 末段=连段结束
   [4] Heavy    Skill=Knife_Heavy Links={}
   ```
   每条 `ComboLink` 配 `Button`（Light/Heavy/Special…）、`Direction`（Any/Forward/Back，做突进/回旋分支）、`TargetNode`。
3. **挂武器**：把图的 Resources 路径填到武器 **`Weapon.ComboGraphPath`**（程序员在 Factory 配）。切到该武器即走连招；**留空 = 该武器无连招**，攻击键回退单招（左键放 `PrimarySkillIndex`、V 放 `SecondarySkillIndex`），完全是接连招前的行为。

### 手感参数（都在 `ComboGraph` 资产上，按连招各自调）

| 字段 | 含义 |
|---|---|
| `BufferWindow` | 输入缓冲窗（秒）：只认"接近取消窗"的预输入；更早的随手点会过期忽视（停手即停连招）。0=不预输入。 |
| `ComboGraceWindow` | 续接宽限窗（秒）：一招收招结束后还保留连招状态这么久，期内点击继续接下一招（治"点击略晚/落在段末边界帧"被误判成重起）。 |
| `DirInputThreshold` | 方向边判定阈值（移动意图模长）：超过才算在按方向（Forward/Back）。 |

> **连点 = 顺图往下接**（Atk1→Atk2→Atk3），停手很快过期、连招停。整串打完（末段无后续边）再点 = 开新一串。取消点早晚改各招 `CancelFromNorm`。

### 加攻击键 / 加渠道

按键语义在 `ComboButton` 枚举（当前 Light=左键、Heavy=V）。要加键：枚举加值 + `InputComponent` 多 `RaiseAttack(...)` 一行 + 图里加用该键的边。下游零改。

## 六、近战吸附（Melee Snap / Magnetism）

技能起手时若前向锥内有敌人，`SkillCastComponent` 自动**转向它 + 前冲收敛到其身前站位**（解决贴脸前冲被胶囊顶歪、空挥不命中）。参数在 `SkillCastComponent` 上（Factory 配，对吸附/连招通用）：

| 参数 | 含义 |
|---|---|
| `SnapEnabled` | 总开关（默认 on）。 |
| `SnapRange` / `SnapHalfAngle` | 捕获半径 / 半角锥：起手在此范围内挑"最正对着"的敌人。 |
| `SnapDesiredGap` | 站位间隙：前冲收敛到距目标这么近就停（停在胶囊外，杜绝顶歪）。≈ 双方胶囊半径和 + 余量。 |
| `SnapTurnRate` | 释放途中持续转向目标的 slerp 速率。 |

> 吸附只对 `ForwardDistance > 0`（前冲招）做距离收敛；`=0`（原地）/ `<0`（后退）招只享转向、位移按 authored 值，不被收敛清零。无目标时回退"按朝向直冲"原逻辑。
