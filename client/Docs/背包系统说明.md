# 背包系统说明

塔科夫/暗黑风格的 **2D 网格空间背包**:物品按形状(可不规则多边形)占一片格子,可拖拽、旋转、堆叠、合并、交换、拆分、整理。

数据全部走打表工具配表(protobuf),不使用 ScriptableObject。物品字段详见 [Item 配表说明](Item配表说明.md)。

> **关于宝箱**:历史上本系统配套过宝箱(概率掉落、整局保持)与背包↔宝箱互拖。该分支已移除宝箱实现(`ChestSystem`/`ChestEntity`/`ChestPanel` 及 `chest`/`chestDrop` 配表均不存在)。但支撑它的两套通用设施仍在,作为扩展点保留:
> - `GridHostPanelBase` 的**集中拖拽含跨网格转移**与 `GridBag.Transfer` 跨容器转移(单网格背包用不到,双网格界面可复用);
> - `IInteractable` + `WorldInteractionSystem` 的**靠近检测 + F 键触发**框架(当前无任何物体实现 `IInteractable`)。
>
> 要重新做宝箱或其它双网格/可交互物,见下方「扩展点」。

## 二、核心模型 GridBag

固定 `Width`×`Height` 网格,一维占位表 `_occ`(0=空,否则=实例 id)做 O(占格数) 重叠检测。
坐标:x=列(向右),y=行(向下),锚点为形状包围盒左上格。物品定义通过构造时传入的 resolver 查询。

**关键 API**

| 方法 | 说明 |
|---|---|
| `TryAddItem(itemId, count)` | 加入若干个:可叠加先并堆再开新堆,返回放不下的剩余 |
| `TryAddItemAt(itemId, x, y, rot, count)` | 在指定锚点放一个新实例 |
| `PlaceOrSwap(instanceId, x, y, rot)` | 移动/合并/交换(同容器拖放落点),失败原位不动 |
| `RotateItem(instanceId)` | 顺时针 90°,原地放不下自动靠边夹回 |
| `SplitStack(instanceId, amount)` | 拆出新堆到空位 |
| `SortBag()` | 合并零散同种堆 + 按面积/权重降序紧凑重排 |
| `static Transfer(from, id, to, x, y, rot)` | **跨容器转移**(双网格界面用,单背包用不到) |
| `RemoveItem` / `GetByInstance` / `GetAt` / `CountItem` / `CanPlace` | 查询与移除 |
| `ToSaveData` / `LoadFromSaveData` | 存档 |

**事件**:任意变化触发 `OnChanged`;`BagGridView` 订阅它自刷新,`BagSystem` 桥接到 `EventMgr.RefreshBagList`。

### 重点行为约定

- **合并**:拖到同种可叠加且未满的物品上 → 合并,超上限的留原位。
- **交换**:拖到唯一异物上 → 两者交换;**对方落位在「本物品已就位」的网格上判定**,避免拖动距离小于物品尺寸时两者共格重叠。交换不干净则整体回滚。
- **整理**:可叠加物品先按 itemId 合并总量,再按占格面积降序 → SortPriority 降序 → id 重排;超单堆上限拆多堆。
- **跨容器转移**(`Transfer`):先试目标锚点精确落位,失败则自动并堆/找空位;部分转移正确扣量,一个都放不下则源不变。

## 三、玩家背包 BagSystem

`IGameService`,默认网格 10×8(`DefaultGridWidth`/`DefaultGridHeight`)。`Init` 建背包、读配表、异步读档;**面板关闭时存档**(`GridHostPanelBase.CommonHide` 调 `Save`,可靠);`Shutdown` 也调 `Save` 但仅尽力而为(退出时异步写盘协程可能来不及)。

```csharp
var bag = ctx.Get<BagSystem>();
bag.AddItem(3001, 80);          // 放入 80 个铁矿石(超单堆上限自动分多堆),返回放不下的剩余
bag.GetItem(id);                // 配表 Item
bag.GetItemType(id);            // ItemType
bag.GetItemQuality(id);         // ItemQuality(决定格背景色)
bag.IsStackable(id);            // 是否可叠加(maxStack>1)
bag.MaxStack(id);               // 单堆上限
bag.UseItem(instanceId);        // 使用(消耗品成功后扣 1)
bag.Discard(instanceId);        // 丢弃(任务物品 QuestItem 受保护不可丢)
bag.SortBag();
bag.Bag;                        // GridBag 实例(UI 渲染它)
```

**使用逻辑**:消耗品效果实现 `IItemUseHandler`,以物品 id 为键 `RegisterUseHandler` 注册。`OnUse` 返回 `true` 且物品为 `ItemType.Consumable` 时由 `BagSystem` 扣 1 个(堆叠减数量,扣到 0 才移除整堆)。`ItemUseContext.Placed` 是**使用前**快照,不要在 handler 里指望读到扣减后的 `count`。当前未内置任何具体处理器实现,按需自行写一个并注册。

**存档**:走框架 `StoreMgr`(键 `BagSave`,`Progress` 分类 → 按存档槽 `slot{id}_` 前缀隔离,异步 JSON 文件)。只存 实例 id/物品 id/坐标/朝向/数量(物品定义不存,读档按配表重算并校验落位合法性)。读写均异步;**可靠存档点是面板关闭**(此后有帧让写盘协程跑完),不能只依赖 `Shutdown`(退出时协程不再恢复会丢档)。存档机制详见 [StoreManager 存档系统使用说明](StoreManagerUsage.md)。

## 四、UI 交互一览

| 操作 | 效果 |
|---|---|
| B 键 | 开/关背包(`BagSystem` 监听 `InputService.OnToggleBagDown`) |
| 左键单击 | 无(不直接使用;使用走右键菜单) |
| 右键单击 | 打开菜单:使用 / 旋转 / 拆分 / 丢弃 |
| 拖拽 | 移动 / 合并 / 交换;实时绿(可放)红(不可放)落点高亮,落点按物品左上角对齐 |
| 悬停 | tooltip:名称(品质色)/ 描述 / 预估价值 |
| 整理按钮 | 紧凑重排 |

**品质背景色**:普通灰 / 优秀绿 / 稀有蓝 / 史诗紫 / 传说橙(集中在 `ItemQualityPalette`)。

## 五、接入清单

1. **打开背包**:`ctx.Get<UIMgr>().Show<BagPanel>()`。
2. **改物品数据**:编辑 `tools/excel/3xlsx/item.xlsx`(先关 Excel),双击 `tools/build_tables.bat` 一键发布,回 Unity 编译。
3. **UI 布局/配色**:改 `BagPrefabBuilder` 后**重跑 Tools/Bag/Build Bag UI Prefabs**(布局是生成时写死的)。

## 六、扩展点

- **新使用效果**:实现 `IItemUseHandler`,`bag.RegisterUseHandler(itemId, handler)`。
- **新物品形状**:配表 `shape` 掩码(如 `"10|11"` L 形),无需改代码。
- **新品质**:`ItemQuality` 枚举 + `ItemQualityPalette` 配色,各补一项。
- **新可交互物**(拾取物/容器入口等):实现 `IInteractable`(`WorldPosition`/`InteractRange`/`Prompt`/`CanInteract`/`Interact()`)并 `WorldInteractionSystem.Register(it)`,即可复用「靠近 + F 触发 + 提示」框架。注:`WorldInteractionSystem` 当前以**主相机位置**为靠近参照(旧玩家系统已移除),接入新角色系统时把参照点换成玩家坐标即可。
- **新双网格界面**(如商店/容器):继承 `GridHostPanelBase`,声明两个 `BagGridView` 并 Bind、重写双击转移,拖拽/`GridBag.Transfer` 转移逻辑自动复用。

## 七、已知约束

- 网格 UI 尺寸在 `BagPrefabBuilder` 里按格数像素硬算(cell 80px):背包 10×8。改格数需同步调窗口尺寸,否则可能溢出。
- 物品左上名称在 1×1 小格会压住图标上部(设计取舍)。
